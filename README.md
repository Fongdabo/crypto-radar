# เรดาร์คริปโต

แอปติดตามเกม NFT เหรียญต้นน้ำ และแอร์ดรอป ติดตั้งได้ทั้งคอมและมือถือ (PWA) อัปเดตข้อมูลทุกเช้า

- `index.html` แดชบอร์ด: โหลด `dashboard/page.html` แล้วรันผ่าน `js/dash.js` ซึ่งอ่านข้อมูลจาก `data/<id>.json`
- `portfolio.html` พอร์ตส่วนตัว เก็บในเครื่องของผู้ใช้ (localStorage) อ่านยอดกระเป๋าแบบดูอย่างเดียวจาก Blockscout
- `sw.js` เปิดได้แม้ออฟไลน์ และดึงเวอร์ชันล่าสุดทุกครั้งที่ออนไลน์
- `scripts/sync.sh` คัดลอกข้อมูลล่าสุดเข้ามาแล้ว push

ข้อมูลเพื่อการศึกษา ไม่ใช่คำแนะนำการลงทุน แอปไม่รับฝากเงิน ไม่เชื่อมกระเป๋า และไม่ขอ seed phrase หรือ private key
