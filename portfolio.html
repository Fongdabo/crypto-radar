กระเป๋าของฉัน

แสดงเฉพาะกระเป๋าที่คุณเพิ่มไว้ กดแท็บเพื่อสลับกระเป๋า กด + เพื่อเพิ่ม แอปอ่านยอดแบบดูอย่างเดียว รองรับ Ethereum และเครือข่าย EVM (Base, Polygon, Arbitrum, Optimism, Ronin), Bitcoin, Solana, Tron และ Stellar

ง่ายสุด: เปิด MetaMask แล้วกดที่ที่อยู่ (0x…) ใต้ชื่อบัญชีเพื่อคัดลอก แล้วกดปุ่มนี้ ไม่ต้องเชื่อมต่อ ไม่ต้องเซ็นอะไร

หรือพิมพ์ที่อยู่เอง

เชื่อมด้วยปุ่มกระเป๋า (ไม่จำเป็น)
ตอนนี้ MetaMask อาจขึ้นป้ายแดงว่าเว็บนี้ "Malicious — flagged as unsafe" เพราะระบบสแกนอัตโนมัติจับเว็บใหม่บน github.io ที่ขอเชื่อมกระเป๋า เรากำลังยื่นเรื่องให้ตรวจใหม่ ระหว่างนี้ ถ้าเห็นป้ายนั้น ให้กด "Back to safety" แล้วใช้ปุ่ม "วางที่อยู่กระเป๋า" ด้านบนแทน ได้ผลเหมือนกัน และปลอดภัยกว่าเพราะไม่ต้องเชื่อมอะไรเลย

กระเป๋าของคุณอยู่ในเบราว์เซอร์ไหน?
กระเป๋าของคุณอยู่ในเบราว์เซอร์อื่น? (เช่น ติดตั้ง MetaMask ไว้ใน Chrome แต่ตอนนี้เปิดด้วย Edge)

เว็บแอปเลือกเบราว์เซอร์ให้เองไม่ได้ ให้เปิดหน้านี้ในเบราว์เซอร์ที่มีกระเป๋าของคุณอยู่แล้ว:

  1. กดคัดลอกลิงก์ (หรือกดปุ่มเปิดในเบราว์เซอร์ด้านบน ถ้ามี)
  2. เปิดเบราว์เซอร์ที่มีกระเป๋าของคุณ แล้ววางลิงก์ในช่องที่อยู่เว็บ
  3. กดแท็บ + เพิ่มกระเป๋า แล้วเลือกกระเป๋าอีกครั้ง
  4. แนะนำ: ติดตั้งแอปจากเบราว์เซอร์นั้น (เมนู ⋮ → ติดตั้งแอป) แอปจะเปิดด้วยเบราว์เซอร์นั้นทุกครั้ง และเห็นกระเป๋าเลย
ถ้ากดเชื่อมแล้วกระเป๋าขึ้นหน้า "Create a new wallet" หรือ "I have an existing wallet" แปลว่ากระเป๋าของคุณไม่ได้อยู่ในเบราว์เซอร์นี้ ให้ปิดหน้านั้นได้เลย อย่านำคำกู้คืน (Seed Phrase) ไปกรอกในเบราว์เซอร์ที่สองเพื่อการนี้ ใช้เบราว์เซอร์เดิม หรือวางที่อยู่เองด้านล่างแทน
แอปนี้จะขอแค่ "ดูที่อยู่กระเป๋า" เท่านั้น จะไม่ขอให้เซ็น อนุมัติ (Approve) หรือส่งธุรกรรมใด ๆ ถ้าเห็นคำขอแบบนั้น ให้กดปฏิเสธทันที

แจ้งเตือนเข้า Telegram

ให้แอปส่งแจ้งเตือนเข้า Telegram ของคุณ ทั้งราคาถึงเป้า และเหรียญในพอร์ตขยับแรงเกิน 10% ใน 24 ชม. ตั้งครั้งเดียวต่อเครื่อง

  1. ใน Telegram ค้นหา @BotFather (มีเครื่องหมายถูกสีฟ้า) พิมพ์ /newbot ตั้งชื่อบอท แล้วคัดลอก token ที่ได้มาวางด้านล่าง
  2. กดเข้าไปที่บอทที่เพิ่งสร้าง แล้วกด Start (หรือพิมพ์อะไรก็ได้ส่งไป 1 ข้อความ)
  3. กลับมากด หา Chat ID ให้ แล้วกด ทดสอบส่ง
token ของบอทเก็บไว้ในเครื่องนี้เท่านั้น ไม่อยู่ในไฟล์สำรอง อย่าส่ง token ให้ใคร ถ้าหลุดให้กด /revoke ใน @BotFather แล้วสร้างใหม่
